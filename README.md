# 六年级 Python 信息科技教学设计

这是一个供 Codex 使用的独立 skill，帮助小学信息科技教师设计适合六年级课堂的 Python 教案。仓库根目录就是 skill 文件夹，包含 `SKILL.md` 和配套参考资料。

默认面向零编程基础、英语薄弱、打字基础薄弱的学生，重点是让任务做得出来、知识学得会、课堂能够及时发现并解决问题。

## 能做什么

- 设计独立单课、完整大单元，或大单元中的单个课时。
- 在写教案前检查教学内容、学习目标和教学重点是否明确；信息不足时先提问，并协助把宽泛目标改成可观察的学习表现。
- 把主要时间留给重难点，减少非核心导入、讨论、汇报与输入，使课堂有快慢节奏。
- 内容聚焦本课知识，尽量减少旧知依赖；凡需使用旧知，先用教师带领、练习题或导学单就近提示进行简短复习。
- 按前课、本课和后课的关系安排单元任务，保持情境与必要命名一致，只调用本课必需的成果。
- 为基础最薄弱的学生提供明确任务和逐步操作提示，说清做什么、在哪里做、怎么做、怎样算完成及遇错如何检查。
- 为每个项目任务安排“学习—练习—应用”，并提供即时反馈、常见错误处理和复验方法。
- 按内容安排学生自学或教师讲解，提供按需观看的微视频方案与等效学习材料。
- 考虑低打字负担、小组互助、操作轮换、不同进度的支持，以及个人学习证据、自评和小组评价。
- 将教案与信息科技课程标准相联系，说明课程要求怎样落实到任务和评价中。

## 在 Codex 中使用

在 Codex 对话中调用：

```text
$primary-python-lesson-design
帮我设计一节六年级 Python 课，主题是变量赋值。
```

也可以直接说明完整需求，例如：

```text
请使用 $primary-python-lesson-design，设计一个四课时的积分系统大单元。
学生零编程基础，每课40分钟；教print、变量、input和整数加法，不学条件与循环。
```

若只说“帮我写 Python 教案”，skill 会先确认设计类型、具体教学内容、目标和重点。设计单元内课时，请提供前课学过的内容或作品，以便安排真实衔接。

## 设计约定

课堂由“导入—新课讲授—总结评价”三个环节组成。新课讲授中的每个项目任务都包含学习、练习和应用；重点由教师讲解并带领练习，简单内容可以自学，微视频用于按需学习和回看。任务安排还包括常见错误的当堂纠正、快慢不同学生的支持、同伴互助和小组评价。

“聚焦重点”同时约束时间和内容：先安排重难点的讲解、操作、练习与纠错时间，再安排简短导入和必要复习；本课尽量少调用旧知，确需使用时必须先复习当前必需部分。“以前学过”不能代替复习，项目连贯也不意味着回忆或重写前课全部程序。

操作支架按基础最薄弱的学生设计，每步都有清楚的动作、位置与完成标志。学生材料使用尊重学生的语言；细化提示同时保留本人思考和操作。教师要求学生自己写的核心代码，不擅自改成整段预置或照抄。

“多层次”有两种具体安排：学得快的学生通过当步检查后，可以先往下走一小步；同一项目任务也可以设置几个递进小任务，前几项非常简单，让全体学生都能完成，最后一项有适度难度，供学有余力的学生挑战。两种安排可选用或结合，基础必做与选做挑战分别评价，后续课堂以全体完成的基础成果为起点。

Python 是教学实现方式，不是课程标准指定的必学语法清单。设计会关注六年级“身边的算法”和“过程与控制”的相关要求，不会把一节 Python 入门课描述为已经完成整个“过程与控制”模块。

## 课程标准依据

课标参考以《义务教育信息科技课程标准（2022年版）》为基础，包括信息意识、计算思维、数字化学习与创新、信息社会责任四项核心素养，以及第三学段（5—6年级）的相关目标。

“过程与控制”包含系统与模块、反馈与优化、逻辑与运算，涉及系统的输入、计算、输出，系统拆分、反馈、开关量与连续量、逻辑运算、编程验证和安全等要求。具体课时只关联本课实际涉及的要求，不用空泛的素养标签代替教学目标。

- [课标依据与正文页码](references/curriculum-2022.md)
- [《义务教育信息科技课程标准（2022年版）》官方附件](https://edu.sh.gov.cn/cmsres/11/1140790acf6f45818df1b9dea7c76679/d3d32c18b09f66dfa3b4c0acfb5277d7.pdf)
- [教育部印发课程标准的通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)

## 安装

这是一个独立 skill，无需 MCP 服务或插件外壳。要从本仓库安装，可在 PowerShell 中运行：

```powershell
git clone git@github.com:songbing1521/a-skill-related-to-instructional-design.git `
  "$env:USERPROFILE\.codex\skills\primary-python-lesson-design"
```

若 Codex 使用自定义的 `CODEX_HOME`，请将克隆路径改为该目录下的 `skills/primary-python-lesson-design`。skill 文件夹应直接包含 `SKILL.md`。
