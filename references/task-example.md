# 一个任务的小循环示例：让积分随赋值变化

这是单课中的一个示范任务，不是默认教案。前提：学生已能运行print程序，并已在前一小步指认变量名；本任务重点是赋值及使用。计划10分钟，分钟数是本例的教学选择。

沿用前一步的积分展示文件。教师过渡：“我们已经找到了保存积分的名字p。现在要让它记住10分，再改成15分；程序会怎样显示？”p在教师卡片中标注为“积分”，不要求学生背英语。

教师预置的可运行起始代码：

```python
p = 10
print(p)
```

基础任务只需把一个数字改为15；教师提供代码，不重敲全文。先完成者可继续做本任务的选做挑战，通过排列现成代码行增加思考深度。

## 学习：3分钟

赋值是本任务难点，由教师讲解。指向`p = 10`，用箭头表示“先看右边的10，把这个值交给左边名称p”；读到`print(p)`时，取p当前对应的值并显示。强调这里的等号是赋值，不是数学中两边可对调的等式。

提问：“电脑先看到右边哪个值？左边哪个名称得到这个值？下一行预计显示什么？”预期学生回答10、p、10。若学生认为输出字母p，教师并排呈现`print("p")`与`print(p)`的结果，学生指出区别，再检查同一问题。

按需支持：计划准备45秒微视频，演示“指右值→箭头指左名→运行输出”；在运行前暂停，让学生先说结果。未制作时标明待准备。无视频时使用同样三步的图文卡，教师讲解不因有视频而取消。

过渡：“知道赋值的方向了，先不碰键盘，判断改值后会输出什么。”

## 练习：2分钟

给出程序纸卡：

```python
p = 8
print(p)
```

每人先预测输出并指明依据，再运行核验。答案为8。回答字母p的学生指出哪一处没有引号，重新预测；把赋值理解为相等的学生用自己的话说明右边的值交给谁。改正后用值9复验，避免带着同一错误进入应用。

过渡：“我们能预测改值后的显示了。现在把同一个积分牌按项目要求更新为15分。”

## 应用：4分钟

项目要求：积分由10变为15，只修改存值处，原来的输出语句继续使用。

在同一应用环节安排三个递进小任务，均计入这4分钟：

| 小任务 | 层次与要求 | 支持与达标证据 |
|---|---|---|
| 1. 看见原积分 | 基础必做：运行现成两行代码，找到显示的10 | 教师预开文件，学生指出输出位置，几乎无需键入 |
| 2. 更新积分 | 基础必做：只把10改成15，预测并运行 | 标出数字修改位置；输出15，本人说清右值交左名、输出读取当前值 |
| 3. 保留两次积分显示 | 选做挑战：用给定的两条赋值语句和两条输出语句排出顺序，让程序先显示10，再显示15，并解释为什么前一次输出仍是10 | 提供四张可排列的代码卡，使用已学赋值与print，不加新语法；参考顺序见下方 |

前两项很容易完成，面向全体；第三项增加对执行次序和当前值的理解，预期主要由学有余力的学生完成。通过当前检查的学生可以先走下一小步；有人做挑战时，其他学生继续完成基础、互助或纠错，结束时一起进入反馈。基础达标不要求完成第三项。

完成代码：

```python
p = 15
print(p)
```

预期输出：

```text
15
```

两人一组，一人修改，一人指认改动并核对结果，随后轮换：另一人将值改为12，先预测再运行并解释。两名学生都要完成一次数字修改和解释。支持者只能指位置或提示，不替对方敲完。

即时反馈：运行出错，先检查是否误删等号、括号或字母；运行成功但输出不符合要求，核对数字改在赋值行还是输出行。修正后重新运行，并说明程序中哪一行保存、哪一行显示。

- 基础达标：能完成一次正确改值、预测输出并解释赋值方向。
- 快生：当前步骤核验后可以接着做下一小任务；完成基础修改和轮换后，尝试小任务3的代码排序并解释两次输出。
- 慢生：教师标出唯一修改位置；同伴按“说预期—指位置—本人改—本人解释”帮助；需要时回看视频或三步卡。

选做挑战的教师参考答案：

```python
p = 10
print(p)
p = 15
print(p)
```

预期先输出10，另起一行输出15。两次print分别读取执行到该行时p的值；后一次赋值不会改写屏幕上已经输出的10。学生只需排列给定代码卡或移动预置行，无需从头打字。未完成挑战者不扣基础达标评价，后续项目也不依赖该挑战成果。

## 反馈与过渡：1分钟

个人选“独立完成／提示后完成／还需帮助”，依据为一次修改和解释；同伴核对双方是否都操作、是否都说清方向。教师抽查易错学生，用一句话回扣本任务。

向后续任务的过渡（仅在后续任务确实如此安排时使用）：“现在积分能按我们修改的值显示了。下一任务把这一段放回完整积分牌，检查组号与积分是否对应。”本例不提前教input、加法或循环。

备注：此任务微评用于及时反馈，整节课的第三环节仍需进行正式的总结、自评和小组评价。10分钟中包含需要支持的学生回看或读卡时间；若符号错误较多，取消快生拓展，把时间用于修正和复验。
